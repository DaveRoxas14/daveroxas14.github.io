<span class="section-label">My Contribution</span>

I was accountable for the implementation of features, tools for other departments, audio/SFX implementations, Save/Load system and content application.

### Feature Implementation and Reusable Code

- **Data Persistence** — I implemented a full Save/Load system that is scalable and fully integrated with all of the features of the game. It uses JSON as its file type and has an option for encryption. It also has some backup systems in case of file corruption.
- **Instructions for Game Creator 2** — I wrote Game Creator 2 Instructions that helped Designers and other departments create content for the game.
- **Escalator System** — I implemented a fully working escalator in the game that can be used by NPCs. Escalators are a visual narrative tool that forces Characters (both player-controlled and NPC) to move from a start point to an end point.
- **Navmesh Links Implementation** — Enabled player and NPC navigation to jump from one navmesh to another.
- **Feature Debugs** — Logs and test options for all features used by all other departments.
- **Project Cleanups and Optimization** — Project cleanups and optimization mid-production to keep everything running smoothly.
- **Documentation** — Fully detailed documentation for each feature I created, enabling other engineers to diagnose features independently.

### Tools for Other Departments

I added several tools in Unity to ease the development process and make other departments' workflows more efficient.

### Audio Implementation with FMOD

I led the implementation of SFX/BGM/AMB with the help and guidance of our Audio Designers.

- **Train System SFX** — A SFX system hooked up to the train system providing audio feedback for arriving, departing, and door events.
- **UI SFX** — UI sound effect implementation.
- **Environment SFX** — Environmental ambient sound implementation.
- **Cutscene BGM** — Background music implementation for cutscenes.

### Content Implementation

I helped Designers implement story content and cutscenes cleanly for easier debugging, and added QoL changes in the provided tools.

<span class="section-label">About the Game</span>

Just as Faye and Rich's painful memories resurface, the two friends are ensnared in the distorted corridors of a decrepit subway station beneath a city still foreign to Faye. To find any path through, they need to decipher all that they have so desperately tried to forget.
